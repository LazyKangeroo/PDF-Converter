--Installation--
  1) Only the 'Main\Build' folder needs to be installed for the program to be usable
  2) The script was include to be change or upgrades as please
  3) There is a shortcut file 'Main/build/exe.win-amd64-3.10/PDF-Converter.exe.lnk'.
    3.1) This shortcut's icon was changed, in-place of the default exe icon.
    3.2) The .ico file was added in the 'Main/build/exe.win-amd64-3.10/'

--Usage--
  1) The specific use of this program is to convert microsoft docx files into pdf files.
  2) Both .doc and .docx files are supported for convertion
     2.1) The script can always be updated to support different img to pdf convertions aswell.

--During Use--
  1) File you want to convert must be 'Dragged and Dropped' onto the programs interactive surface (The light blue area).
     1.1) Anywhere where the file would be dropped would be recoreded.
  2) When after dropping file
     2.1) If a file type which isn't supported was dropped, the screen of the program would turn red.
      2.1.1) To reset the file/redo the process - if the wrong file type was dropped - click the 'Press to Convert' text or anywhere in the grey area of the program.
      2.1.2) The programs surface would turn back to blue once the file selection was reset.
     2.2) If a file type which is supported was dropped, the screen of the program would turn purple.
       2.2.1) To start the converting process click the 'Press to Convert' text or anywhere in the grey area of the program.
       2.2.2) The programs surface would turn back to blue once the file convetion was complete and when another file can be selected ('Dragged and Dropped') to be converted.
         2.2.2.1) Note that the convertion process may take a while depending on the size of the file selected.
  3) After the convertion process was completed the converted file will appear in the same folder as the file you converted.
     3.1) If there was anything wrong with the convertion or the file wasn't converted, try the process again. The error may have been a technical error
  4) It is IMPORTANT to note that if you select multiple file to be converted the program will ONLY CONVERT THE FIRST file you selected.
